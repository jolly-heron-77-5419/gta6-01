SOLMAR BAY is an original open-world crime game in the browser: explore a sun-soaked coastal city on foot and by car, steal cars, dodge the police under a 5-star wanted system, and run a three-job story for the fixer Lena Cruz — all rendered in 3D with three.js, with a live minimap HUD and synthesized sound, from static files with no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Drive with WASD, steal a car with E, punch with F, pause with P.
