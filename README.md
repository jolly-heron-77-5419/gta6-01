SOLMAR BAY is an original open-world crime game set in a sun-soaked fictional coastal city: steal cars, outrun the police, and run three jobs for fixer Lena Cruz — all offline in a desktop browser, built with three.js and synthesized sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Start the job.
